> ### АНТИВИРУСНЫЕ СРАБАТЫВАНИЯ
> Антивирус может отреагировать на WinDivert.  
> WinDivert перехватывает и фильтрует сетевой трафик — именно это требуется zapret для работы.
> Такой инструмент способны применять и безопасные, и вредоносные программы, однако сам WinDivert вирусом не является.
>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) из репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Ряд антивирусов классифицирует файлы WinDivert как инструменты повышенного риска или хакерские средства. В результате файл удаляется и отправляется в карантин. В названии обнаружения обычно присутствует `WinDivert` либо `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте каталог zapret в исключения антивируса или отключите обнаружение PUA — потенциально нежелательных приложений. Например, в Kaspersky это настройка "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы точно понимаете настройку исключений, лучше добавить исключение; при недостатке уверенности рекомендуется отключить обнаружение PUA.

## ⚙️Использование

1. Сначала включите безопасный DNS (Secure DNS).
    * В Chrome активируйте "Использовать безопасный DNS" и выберите DNS-провайдера, отличного от "Поставщика по умолчанию".
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например, `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован.
    * Windows 11 позволяет включить Secure DNS непосредственно в настройках системы — [инструкция доступна здесь](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот вариант рекомендуется.
    * Владельцам роутеров Keenetic нужно включить в настройках параметр "Транзит запросов". Если его отключить, настройка и работа Secure DNS на компьютере могут завершиться проблемами.

2. Загрузите zip- или rar-архив с [последнего релиза](https://github.com/Devilbeyondburst/zapret-discord-youtube/releases/latest).

3. Откройте свойства скачанного архива и установите флажок "Разблокировать". При использовании 7-Zip или PeaZip этот пункт можно не выполнять.

4. Распакуйте архив в каталог, путь к которому не содержит кириллицу и специальные символы.

5. Запустите необходимый файл.
    * Для поиска подходящей стратегии откройте **`service.bat`** и выберите `Run Tests` -> `Standard tests` -> `All configs`.
    * Чтобы включить автоматический запуск, в **`service.bat`** выберите `Install Service` и затем нужную стратегию.

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии.

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдёте подходящую именно для вас**.

- [**`service.bat`**](./service.bat) — установка автозапуска и дополнительные инструменты:
  - <ins>**`Install Service`** — добавление выбранной стратегии в автозапуск служб (services.msc).</ins>
  - **`Remove Services`** — удаление стратегии и WinDivert из служб.
  - **`Check Status`** — просмотр состояния обхода и служб, включая автозапущенную стратегию и WinDivert.
  - **`Game Filter`** — изменение режима обхода для игр и прочих сервисов, работающих с UDP и TCP-портами выше 1023.  
  **После изменения параметра стратегию необходимо перезапустить.**  
  Значение в скобках показывает, включена функция или выключена.
  - **`IPSet Filter`** — изменение режима обхода для сервисов, перечисленных в `ipset-all.txt`.  
  Это может пригодиться при диагностике ресурса, который без zapret доступен, а с ним не работает.  
  В скобках отображается текущее состояние:
    - `none` — ни один IP не проходит проверку;
    - `loaded` — IP проверяется на наличие в списке;
    - `any` — под фильтр попадает любой IP.  
  - **`Auto-Update Check`** — включение или отключение автоматической проверки обновлений.
  - **`Replace active fakes`** — замена текущего фейка на другой файл из каталога `bin`.
  - **`Update IPSet List`** — загрузка актуального `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** — обновление hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**.</ins>
  - **`Check for Updates`** — ручная проверка наличия обновлений.
  - **`Run Diagnostics`** — поиск распространённых причин неисправности zapret.  
  В конце доступна очистка кэша <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это может помочь, если приложение внезапно перестало работать.
  - **`Run Tests`** — запуск проверки стратегий:
    - `Standard tests` — тестирование сайтов из `utils/targets.txt`;
    - `DPI checkers` — проверка DPI у разных провайдеров, включая Cloudflare, Amazon и другие.


## ☑️Распространенные вопросы и проблемы

### После запуска скрипта `general*` ничего не происходит

При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe (обход), видимый на панели задач.  
Если этого не случилось, ознакомьтесь с [#522](https://github.com/Devilbeyondburst/zapret-discord-youtube/issues/522).

### Ни одна стратегия не подходит
- Откройте командную строку с правами администратора.
- Выполните по очереди следующие команды:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер.

### Не работает телеграм (веб версия)

Откройте **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открывшегося блокнота.
  - Через текстовый редактор, запущенный от имени администратора, откройте файл `hosts` в появившейся папке.
  - Вставьте скопированное в конец файла `hosts` либо замените ранее добавленные аналогичные строки.
  - Сохраните файл и проверьте подключение ещё раз. Если результата нет, убедитесь, что hosts действительно был сохранён.

#### Работа не гарантируется. Если способ не помог, используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/Devilbeyondburst/tg-ws-proxy) или любым публичным прокси.

### Обход не работает или перестал работать

> [!IMPORTANT]
> **Стратегии способны со временем терять работоспособность.**
> Вариант, который некоторое время работал, может перестать подходить после его обнаружения.
> Здесь доступно много разных стратегий обхода. Если ни одна не помогает, создайте новую на основе одной из существующих и измените её параметры.
> Описание параметров стратегий находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте наличие ошибок через `service.bat` -> `Run Diagnostics`.

- Убедитесь, что нужный адрес присутствует в списках доменов или IP.

- Проверьте другие варианты (**`ALT`**, **`FAKE`** и прочие).

- Выполните полную переустановку по инструкции ниже.

- Дополнительная информация: [#765](https://github.com/Devilbeyondburst/zapret-discord-youtube/issues/765).

### Как полностью переустановить или обновить?
- Сохраните добавленные вами ресурсы и данные.
- Перезапустите устройство.
- Откройте `service.bat` -> `Remove Services`.
- Запустите `service.bat` -> `Run Diagnostics`; исправьте найденные ошибки, затем в конце выберите Y.
- Удалите каталог zapret.
- Загрузите свежую версию со [страницы релизов](https://github.com/Devilbeyondburst/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`).
- Кликните по архиву правой кнопкой, откройте свойства. Если внизу справа есть флажок разблокировки, установите его, нажмите применить и ОК.
- Распакуйте архив в новую папку в корне диска; путь не должен содержать пробелы и специальные символы.
- Запускайте разные скрипты `general` и проверяйте доступность ресурсов. Если очередная стратегия не помогает, закройте программу через значок замка на панели задач и попробуйте следующую.
- После выбора рабочей стратегии установите её в автозапуск через `service.bat` -> `Install Service` -> нужная стратегия.

### Не работает игра или приложение при включённом запрете

- В `service.bat` проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может повлиять на ресурсы, которые вы не собирались обходить.

### Античит ругается на WinDivert

- Изучите инструкцию: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Требуется цифровая подпись драйвера WinDivert (Windows 7)

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert остаётся среди служб

1. Узнайте имя службы командой в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, включён ли [Secure DNS](#%EF%B8%8Fиспользование).
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Если рабочая стратегия перестала помогать, переберите остальные.
- См. также [#251](https://github.com/Devilbeyondburst/zapret-discord-youtube/discussions/251).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что настроен [Secure DNS](#%EF%B8%8Fиспользование).
- Сначала желательно определить стратегию, с которой открывается сайт YouTube, и запустить её.
- В `service.bat` перейдите в `Run Diagnostics` и очистите кэш Discord.
- Проверьте приложение Discord и выясните, помогла ли очистка.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, её можно использовать.
- Если Discord не открывается и в браузере, повторно проверьте все стратегии. Возможна ситуация, когда YouTube работает на одной стратегии, а Discord — нет.
- См. также [#252](https://github.com/Devilbeyondburst/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/Devilbeyondburst/tg-ws-proxy).
- Также можно использовать бесплатные MTProto-прокси из интернета.

### Не работают игры

Игр много, поэтому проверить и исправить каждую из них невозможно.

Наиболее универсальный порядок действий:
- через `service.bat` обновите ipset и включите `Game Filter`;
- если это не помогло, дополнительно включите `ipset any`.

Учтите: при активном `ipset any` многие сайты могут перестать открываться. Не оставляйте этот режим включённым постоянно. Определите IP-адреса, которые использует игра, и внесите их в `ipset-all.txt`.

Если результата нет, создайте обсуждение в разделе [Discussions](https://github.com/Devilbeyondburst/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Не нашли подходящего ответа

- Опишите проблему [здесь](https://github.com/Devilbeyondburst/zapret-discord-youtube/issues).

## 🗒️Добавление адресов прочих ресурсов

Расширить перечень адресов для обхода можно с помощью следующих файлов:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически;
- **`list-exclude-user.txt`** — домены, которые нужно исключить, например когда IP-сеть присутствует в `ipset-all.txt`, но конкретный домен фильтровать не требуется;
- **`ipset-all.txt`** — IP-адреса и подсети;
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, подлежащие исключению.
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` либо `service.bat`.
